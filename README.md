# Mini GPT (Karpathy-inspired)

This project is a simple implementation of a GPT-style language model inspired by Andrej Karpathy's tutorial.

## 🚀 Features
- Character-level language model
- Trained on Shakespeare dataset
- Implemented using PyTorch

## 📂 Dataset
- Shakespeare Plays dataset (Kaggle)
- Converted into raw text format for training

## ⚙️ Tech Stack
- Python
- PyTorch
- Google Colab

## 🧠 What I Learned
- Tokenization and vocabulary building
- Sequence modeling using neural networks
- Training loops and loss optimization
- Basics of GPT architecture

## ▶️ How to Run
1. Open `mini_gpt.ipynb` in Colab
2. Run all cells
3. Train the model and generate text
